Datenschutz

Diese App dient nur der Planung von Rubens 50. Geburtstag. Hier steht, welche Daten gespeichert werden und was damit passiert.

Verantwortlich

Ruben Gläser, ruben.glaeser@icloud.com

Welche Daten gespeichert werden

  • Nutzername, Anzeigename und Personenanzahl
  • Deine PIN, nur verschlüsselt als Prüfwert. Niemand kann sie im Klartext lesen, auch Ruben nicht.
  • Deine Einträge in der Mitbringliste
  • Hochgeladene Partyfotos mit Name und Uhrzeit. Die Fotos werden verkleinert, und eingebettete Metadaten wie GPS-Standort und Kameradaten werden beim Hochladen entfernt.

Wo die Daten liegen

Die Seite selbst wird über GitHub Pages ausgeliefert. GitHub verarbeitet dabei technisch notwendige Zugriffsdaten wie die IP-Adresse. Die Daten der App liegen auf einem Server von Perplexity AI. Die Daten liegen in einer Datenbank der App auf diesem Server. Die Server von Perplexity können auch außerhalb der EU stehen, zum Beispiel in den USA.

Wer die Daten sieht

  • Angemeldete Gäste sehen Anzeigenamen, Personenanzahl, die Mitbringliste und die Partyfotos.
  • Ruben sieht im Admin-Bereich zusätzlich die Nutzernamen.
  • Es gibt keine Weitergabe an Dritte, keine Werbung, kein Tracking und keine Analyse-Tools.

Auf deinem Gerät

Damit du angemeldet bleibst, speichert dein Browser einen Anmeldeschlüssel. Er wird beim Abmelden gelöscht. Es gibt keine Werbe- oder Tracking-Cookies. Die Schriften werden direkt von dieser App geladen und nicht von Google.

Kalenderexport

Die Kalenderdatei enthält die Gäste- und Mitbringliste zum Zeitpunkt des Downloads. Sie liegt danach nur in deinem eigenen Kalender.

Suchmaschinen

Die App ist für Suchmaschinen gesperrt und nur über den direkten Link erreichbar.

Löschen

Eigene Fotos und Mitbring-Einträge kannst du jederzeit selbst löschen. Wenn du dein Konto komplett löschen lassen möchtest, wende dich an Ruben.
